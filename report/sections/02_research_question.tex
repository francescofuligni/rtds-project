\section{Research Problem and Question}
% Define the gap and state the research question and sub-questions.

A single average reconstruction error does not show how results depend on attacker
knowledge or which records are exposed. We ask: \emph{when $m$ sparse trees from one
Rashomon set are released with leaf class counts, how well can an attacker reconstruct
sex, and estimate which full-record claims are correct?}
\begin{description}[leftmargin=1.2em,itemsep=0pt,topsep=2pt]
  \item[SQ1.] How much do known marital status, education or age help, compared with
      releasing more trees?
  \item[SQ2.] How does random tree selection compare with TreeFARMS enumeration order?
  \item[SQ3.] Can public data guide reliable record-level confidence, and how much
      public data is needed?
\end{description}
SQ2 extends the release-policy comparison already studied by
\citet{hsu2026rashomon}. We adapt DRAFT and use repeated solving guided by public
data, following a similar idea to \citet{dick2023confidence}.
