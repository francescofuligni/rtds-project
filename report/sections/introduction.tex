\section{Introduction}
\label{sec:introduction}

Releasing a trained model is often treated as safer than releasing the data it was trained on. Recent work complicates that assumption: for simple, interpretable model classes like decision trees, an attacker who knows a model's structure and the per-leaf class counts can set up a constraint-satisfaction problem whose solution is, in many cases, close to the exact training data -- a \emph{dataset reconstruction attack} \citep{ferry2024draft}. This risk compounds when, instead of a single released model, a whole \emph{Rashomon set} of near-equally-good models is available: TreeFARMS \citep{xin2022treefarms} exhaustively enumerates every decision tree within a bound of the optimal training objective, and releasing (or simply having an attacker enumerate) several of these trees gives several independent sets of constraints on the same underlying data, each of which narrows down the space of datasets consistent with all of them.

Two open questions from this literature motivate this project. First, \citet{hsu2026rashomon} establish that releasing \emph{more} trees from a Rashomon set lowers average reconstruction error, but says less about \emph{what else} drives reconstruction success -- in particular, how much an attacker's own background knowledge (auxiliary attributes already known about the target individuals) changes the picture, holding the released trees fixed. Second, no work we reviewed attaches a validated confidence value to an individual reconstructed record; attacks are evaluated by an aggregate error rate over the whole reconstructed table, which is the wrong granularity for an auditor or data subject asking "how much should I trust \emph{this specific} reconstructed row?"

This project addresses both gaps empirically, within the scope of a three-week course project (an MVP, not an exhaustive study). We reconstruct a sensitive attribute $T=\texttt{sex}$ from Rashomon sets built on a curated subset of the UCI Adult dataset, under four background-knowledge conditions that vary which auxiliary attributes ($A=\texttt{marital-status}$, $B=\texttt{education}$) the attacker is assumed to already know, and across a sweep of how many trees are released. We then go further and build a per-row confidence signal from solver agreement across repeated re-solves, and calibrate it into an actual validated probability using isotonic regression on a held-out split. Section~\ref{sec:method} describes the experimental setup, Section~\ref{sec:results} reports the findings -- including a hypothesized structural mechanism we tested directly and found did not hold up as expected -- and Section~\ref{sec:conclusion} summarizes the contribution and its limitations.
