\begin{abstract}
% Student-authored abstract.
A decision tree is often published together with the number of training examples of each
class in every leaf, and an attacker can use these counts to reconstruct the training data.
We study this for sparse trees from one Rashomon set (trees that all fit the data almost
equally well), trained on samples of 100 people from the UCI Adult census dataset. We ask how much it helps the attacker to already
know some attributes when reconstructing sex, and whether the attacker can tell which
reconstructed records are correct. The error drops mainly when more trees are released, and
when they are chosen at random instead of in the order in which TreeFARMS lists them; known
attributes help only a little. By solving the reconstruction repeatedly with guidance from
public data, the attacker gets a confidence per record that is close to its accuracy on
average, and can point out almost half of the records with very few mistakes. With little
public data, a Dirichlet prior keeps this confidence from becoming too high.
\end{abstract}
