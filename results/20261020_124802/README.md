# Historical results archive

This directory groups the existing reconstruction and calibration outputs.
The directory timestamp records archival time in Europe/Stockholm, not experiment time.
No experiment or analysis was rerun during this move; all ten output files are unchanged.

These CSVs belong to the historical known-Y / truth-aligned confidence protocol.
They do not contain the current protocol metadata and cannot validate the no-Y method.
Current analysis scripts reject them as incompatible; this is expected.
The bundle includes both experiment CSVs, four PDF figures and four text summaries.
